Rhenium is a web browser for Android TV. Users can download APK files from websites and choose Open file in Downloads to install them. REQUEST_INSTALL_PACKAGES allows Rhenium to hand the selected APK to Android's package installer. Users must explicitly allow installation from Rhenium and confirm the installation in Android's installer. Rhenium does not install apps automatically, bundle other APKs, or use this permission for an in-app self-update mechanism.
